# Media and reading

## Confirmed facts

- Videos support URL or local file references, notes, optional thumbnails, and completion status.
- Reading supports editable local text, font-size adjustment, scrolling, spacing, and completion.
- Audio supports URL or local file references, playback controls, seek/progress/duration, and optional remembered position.

## Unknowns

- Native playback, YouTube handling, and local-file picker details are undecided.
